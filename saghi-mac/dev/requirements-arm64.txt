# Saghi arm64 (Apple Silicon) requirements -- the distribution stack
# (see packaging/build_bundle.py for how it is used).
#
# From 0.3.0 the speech engine is transcribe.cpp (the `transcribe-cli` binary
# plus a GGUF model file, both shipped beside the app, see saghi/gguf_engine.py).
# The PyTorch stack (torch, transformers, accelerate, safetensors, sentencepiece,
# protobuf, tokenizers, huggingface_hub, librosa and its numba/scikit-learn
# tree, scipy) is no longer installed: saghi/engine.py (the PyTorch engine)
# stays in the repo for developer machines and imports torch lazily.
#
# macOS floor: 13.0, set by PySide6 6.11.2 (its wheel is tagged
# cp310-abi3-macosx_13_0_universal2); every other package here has a floor at
# or below 13.0.
